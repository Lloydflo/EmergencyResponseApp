Build limitation in this execution environment
----------------------------------------------
A full Android Gradle build was not completed here. The wrapper attempted to retrieve
Gradle 8.10.2 from services.gradle.org, but this runtime has no external network access
(UnknownHostException). The runtime also has no installed Android SDK. This is an
environment limitation, not a successful assembleDebug result. Final confirmation must
be performed through Android Studio Gradle Sync, Build > Rebuild Project, and device tests.

Runtime/server requirement
--------------------------
The Android client is complete for receiving these events, but true notifications while
the app process is not open require the PHP/dispatch backend to send high-priority,
data-only FCM messages after the chat, broadcast, or assignment transaction commits.
The server source and Firebase service-account credential were not present in the uploaded
Android project, so remote server deployment cannot be validated here. Use the exact
contract in FCM_NOTIFICATION_PAYLOADS.md.

Android platform limits
-----------------------
- Android 13+ requires the user to grant Notifications permission.
- Users can mute a channel or vibration in system settings.
- A manually Force-stopped app does not receive FCM until reopened.
- Manufacturer battery-management policies can delay FCM delivery.
