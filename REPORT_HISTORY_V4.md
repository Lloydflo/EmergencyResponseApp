# Report History v4 (Android 17.3 / 26)

This source includes the Report screen update requested after v3:

- the visible **Operational snapshot** block is removed;
- Pending / Submitted / Approved review status remains;
- Approved reports stay in the active Approved list for 24 hours;
- after 24 hours they appear automatically in the read-only **History** tab;
- History is grouped and filterable by approval month;
- Create Report, Needs Revision, PDF export, equipment requests, and voice messaging remain.

Deploy the matching v4 `api_app` backend before installing this Android build. See the delivery bundle's `README_DEPLOYMENT_TAGALOG.md` for the exact order and migration.
